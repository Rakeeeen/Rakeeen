# Rakeeen — portfolio

Hamed Walid's portfolio: React 19, TypeScript, Vite and Firestore, in English,
Arabic (RTL) and Italian.

```bash
npm install
cp .env.example .env   # fill in the Firebase and EmailJS values
npm run dev            # http://localhost:3000/Rakeeen/
npm run build
npm run deploy         # publishes dist/ to GitHub Pages
```

How the code is organised: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
